# KantoVault NZ

Aotearoa's online storefront for **building-block construction sets** — featuring 36 brick sets from 5+ starter kits to 2,000+ piece display models, shipped nationwide from Auckland.

## Highlights
- **36 Building-Block Sets**: Spanning **City & Vehicles**, **Architecture & Landmarks**, **Space & Science**, and **Fantasy & Adventure**, plus bulk brick tubs.
- **New Zealand Storefront**: All prices in NZD (15% GST included), free tracked NZ shipping over NZ$100, and interactive product cards & drawer checkout.
- **Tech Stack**: React 19, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons.

## Local Development
```bash
npm install
npm run dev
npm run build
```
