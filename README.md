# KantoVault NZ

Aotearoa's curated luxury storefront for **authenticated, factory-sealed vintage Pokémon boxes, WOTC theme decks, collector tins, and classic blister packs** — featuring 36 verified collector pieces priced up to **NZ$1,600**.

## Highlights
- **36 Real Vintage Sealed Products**: Spanning WOTC (1999–2001), EX & Classic (2003–2010), XY Era (2014–2016), and Special / Sun & Moon grails.
- **New Zealand Collector Experience**: All pricing in NZD (GST inclusive), Auckland Vault provenance, insured overnight NZ courier progress tracker, and NZ regional checkout.
- **Tech Stack**: React 19, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons.

## Local Development
```bash
npm install
npm run dev
npm run build
```
